1. Install the 0.5.0 Content Manager ZIP and portable companion. Keep the companion open. Select the installed FH26 car and one exact track/layout.
2. Choose WIMNA AI Baseline for the first short session. Set and note the tire compound, starting fuel, weather/air and track temperatures, energy target/map, setup and assists. The paired modes should start AI collection automatically only after mode, physics and recorder checks pass. Confirm Recorder ON, samples increasing and AI control readback ON. If automatic start is blocked, check the displayed reason; Start AI Recording remains the manual fallback.
3. End Collection Run to save the trace. This does not brake the car or release AI steering. Exit the session through the game menu while AI remains in control, or stop safely and use Stop AI Driver at Rest only at 2 km/h or less with a person ready to steer. Verify native AI OFF before driving.
4. Start a separate WIMNA AI Plan C Prototype session on the same track with the same tire, starting fuel, weather, energy map, setup and assists. Recheck the observed starting state; a new session cannot inherit physical tire, fuel or battery state. Confirm the prototype ID and parameter hash, native AI ON, recorder activity and saved crossings. The mode's worker request alone does not prove an applied force or lap-time benefit.
5. Expect native Plan C laps to be marked invalid when the CSP force runs; AI takeover can also invalidate a native lap. Keep full crossing times and raw telemetry with cut, spin, reset and gap flags. Do not call these official clean laps. Export both runs and inspect the paired data before considering a longer test.

Data collection comes first. In Content Manager, choose the car, track/layout, tire and physical weather setting. Select WIMNA AI Thermal for automatic AI control; select WIMNA Test or Practice for manual collection. In the WIMNA app, optionally enter a tire test label (X/Y/Z), requested compound, condition label and setup/profile label, then press Start Recording or Start AI Recording. Every lap crossing is counted as raw data regardless of validity; quality is labeled separately. Record one stint and mark the pit/control handoff. Stop the car, have a driver ready, then use Stop AI Driver at Rest and verify native AI-OFF readback before taking over. Box, change tires, end the stint, and start the next labeled stint. The run keeps recording through the handoff. End Collection Run closes recording without switching AI off; if AI remains ON, let it drive until safely stopped or exit through the game menu. AI and human samples use the same raw simulator telemetry; controller identity is recorded per sample. Collection has no clock or lap quota. Requested labels are not native readback, and setup/profile identity is unverified without a hash.
